# Инженерная документация

- `PROJECT-PROFILE.md` — обязательный выбор профиля `BACKEND_ONLY` / `ANDROID_ONLY` / `FRONTEND_ONLY` / `BACKEND_AND_ANDROID` / `FULL_STACK` / `BACKEND_WEB_AND_ANDROID` и маршрутизация профильных агентов.
- `spec/` — утверждённая спецификация и handoff-пакет.
- `SMALL-PROJECT-START.md` — сценарий первого тестового прогона на небольшом backend-only кейсе.
- `ANDROID-START.md` — сценарий первого тестового прогона на native Android/Kotlin проекте.
- `QUALITY-GATES.md` — Definition of Ready / Definition of Done и release gate.
- `decisions/` — Architecture Decision Records.
- `test/` — тест-план, тест-репорты, дефекты.
- `review/` — отчёты code review.
- `release/` — release checklist, release notes, known issues.

Не редактируйте оригинал утверждённой спецификации без процедуры change request. В случае изменения требований сохраняйте новую версию и указывайте её в каждом отчёте.
